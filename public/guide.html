01

การเลือกสินค้า

  1. เปิดเว็บไซต์และเลื่อนไปยังหัวข้อ รายการสินค้า
  2. ค้นหาสินค้าได้ด้วยช่อง ค้นหาสินค้า...
  3. กรองตามหมวดหมู่ เช่น ขนม ทริม POP หรือ TOP สถานะสินค้า และเรียงราคาได้
  4. เปลี่ยนรูปแบบการแสดงผลระหว่างมุมมองตาราง รายการ และกะทัดรัด
  5. ตรวจสอบราคา ขนาดที่จำหน่าย และจำนวนสินค้าคงเหลือ
  6. กด เลือก ที่สินค้าที่ต้องการ

สินค้าที่ขึ้นว่า รอรีสต็อก หรือมีสต็อกไม่พอ จะยังไม่สามารถกดสั่งซื้อได้

02

การเพิ่มสินค้าลงตะกร้า

  1. เลือก ขนาด / เรทราคา
  2. ระบุ จำนวนแพ็ก
  3. ตรวจสอบจำนวนสูงสุดที่สามารถสั่งได้
  4. กด เพิ่มลงตะกร้า

ตัวเลขข้างสัญลักษณ์ตะกร้ามุมขวาบนจะแสดงจำนวนรายการที่เพิ่มไว้

03

การตรวจสอบตะกร้า

  1. กดเมนู ตะกร้า ด้านล่าง หรือสัญลักษณ์ตะกร้ามุมขวาบน
  2. ตรวจสอบชื่อสินค้า ขนาด ราคา และจำนวน
  3. ใช้ปุ่ม − หรือ + เพื่อปรับจำนวน
  4. ตรวจสอบยอดสินค้า ค่าจัดส่ง และยอดรวม
  5. กด กรอกข้อมูลและสั่งซื้อ

ค่าจัดส่งและยอดรวมอาจเปลี่ยนแปลงได้ ควรตรวจสอบอีกครั้งก่อนยืนยัน

04

การกรอกข้อมูลจัดส่ง

กรอกชื่อผู้รับ เบอร์โทรศัพท์ ที่อยู่สำหรับจัดส่ง รหัสตัวแทน (ถ้ามี) และหมายเหตุเพิ่มเติม (ถ้าต้องการ)

ตรวจสอบชื่อ เบอร์โทร และที่อยู่โดยละเอียด เพราะร้านค้าจะใช้ข้อมูลเหล่านี้ในการจัดส่ง

05

การเลือกวิธีชำระเงิน

โอนเงิน / QR Code

  1. เลือก โอนเงิน / QR Code
  2. สแกนผ่านแอปธนาคาร หรือกด ดาวน์โหลด QR Code
  3. ตรวจสอบชื่อบัญชีและยอดเงินก่อนโอน
  4. เก็บสลิปไว้เพื่อแนบหลักฐานหลังสร้างออเดอร์

เก็บเงินปลายทาง

เลือก เก็บเงินปลายทาง (COD) เมื่อคำสั่งซื้อและพื้นที่จัดส่งรองรับ แล้วชำระเงินเมื่อได้รับสินค้า

วิธีชำระเงินที่แสดงขึ้นอยู่กับช่องทางที่ร้านค้าเปิดใช้งานในขณะนั้น

06

การยืนยันคำสั่งซื้อ

ก่อนกด ยืนยันสั่งซื้อ ให้ตรวจสอบสินค้าและจำนวน ชื่อและเบอร์โทร ที่อยู่จัดส่ง วิธีชำระเงิน ค่าจัดส่ง และยอดรวม เมื่อข้อมูลถูกต้องแล้วจึงยืนยัน และเก็บเลขออเดอร์หรือภาพหน้าจอไว้

07

การติดตามออเดอร์และแนบหลักฐาน

  1. กด ติดตามออเดอร์ ด้านบน หรือเมนู ออเดอร์ ด้านล่าง
  2. เลือกคำสั่งซื้อที่ต้องการตรวจสอบ แล้วดูสถานะล่าสุด
  3. หากชำระด้วยการโอนเงิน ให้แนบหลักฐานจากหน้าออเดอร์
  4. เมื่อร้านเพิ่มเลขพัสดุแล้ว สามารถกดลิงก์ติดตามพัสดุได้จากใบออเดอร์
  5. กด พิมพ์ / บันทึก PDF เพื่อเก็บใบเสร็จ

กลับมาตรวจสอบหน้านี้เป็นระยะเพื่อดูการยืนยันชำระเงินและสถานะจัดส่ง

08

เมนูอื่น ๆ

  • สินค้า — กลับไปยังรายการสินค้า
  • บัญชี — ดูข้อมูล รหัสประจำตัว เปลี่ยนรูปบัญชี ดูเครดิต พอยส์ และของรางวัล
  • ติดต่อ — ติดต่อร้านค้าผ่าน LINE
  • ปุ่มรูปคนด้านบน — เปิดบัญชีของเบราว์เซอร์ปัจจุบัน

เพื่อให้ออเดอร์เดิมยังแสดงอยู่ ควรใช้อุปกรณ์และเบราว์เซอร์เดิม และหลีกเลี่ยงการล้างข้อมูลเว็บไซต์ก่อนคำสั่งซื้อเสร็จสมบูรณ์

ข้อควรระวัง

  • ตรวจสอบสถานะคงเหลือก่อนสั่งซื้อ
  • ตรวจสอบยอดและชื่อบัญชีก่อนโอนเงินทุกครั้ง
  • อย่าเปิดเผยสลิปหรือข้อมูลส่วนตัวในพื้นที่สาธารณะ
  • เก็บเลขออเดอร์และหลักฐานการชำระเงินไว้จนกว่าจะได้รับสินค้า
  • หากสถานะไม่อัปเดตหรือพบปัญหา ให้ติดต่อร้านค้าทาง LINE
  • โปรดตรวจสอบข้อจำกัดด้านอายุ สุขภาพ และกฎหมายที่เกี่ยวข้องในพื้นที่ของคุณก่อนสั่งซื้อหรือใช้สินค้า
