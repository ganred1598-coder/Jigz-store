# JIGᶻ AGENT Store — Cloudflare

ระบบหน้าร้านและหลังบ้านสำหรับ JIGᶻ AGENT บน Cloudflare Workers + D1

## ฟังก์ชันรุ่น 4.2.0

- ไทม์ไลน์ออเดอร์สำหรับลูกค้า: รับออเดอร์ → ตรวจสอบ/ชำระ → กำลังแพ็ก → จัดส่งแล้ว → สำเร็จ
- ปุ่มคัดลอกและแชร์เลขพัสดุ รองรับ Web Share บนมือถือ
- หน้าแอดมินเลือกบริษัทขนส่งหลักในไทยได้เร็วขึ้น: Thailand Post, Kerry, Flash, J&T, SPX และ Ninja Van
- ขั้นตอน COD แบบปลอดภัย: ลูกค้ายืนยันรับสินค้า → แอดมินยืนยันยอด COD → จึงปิดออเดอร์ได้ พร้อม Audit Log

- เลขพัสดุในใบออเดอร์และประวัติออเดอร์เป็นลิงก์กดติดตามได้ รองรับการตรวจจับบริษัทขนส่งผ่านหน้าติดตามกลาง
- ลูกค้าพิมพ์ใบสรุปออเดอร์หรือบันทึกเป็น PDF ได้จากหน้ารายละเอียดและหน้าประวัติออเดอร์

- OWNER แต่งตั้ง/ถอดสิทธิ์ ADMIN จากผู้ใช้รายอุปกรณ์ได้ในเมนู `ผู้ดูแลระบบ`
- เพิ่ม แก้ไข และลบสินค้าได้จากหลังบ้าน โดยปุ่มลบสงวนให้ OWNER และเก็บประวัติออเดอร์เดิม
- ลูกค้าเลือกมุมมองสินค้าแบบตาราง รายการ หรือกะทัดรัดได้ ระบบจำมุมมองไว้ในอุปกรณ์

- Web Push Notification สำหรับอุปกรณ์แอดมิน พร้อมแจ้งออเดอร์ใหม่อัตโนมัติ ปุ่มเปิด และส่งทดสอบ
- หน้าร้าน responsive พร้อมสินค้า ค้นหา ตัวกรอง เลือกขนาด ตะกร้า และตรวจสต็อกจริง
- สร้างออเดอร์ออนไลน์ ชำระแบบโอน/COD แนบหลักฐาน ติดตามพัสดุ ยืนยันรับสินค้า และพิมพ์/บันทึกบิล
- โปรไฟล์ลูกค้า ที่อยู่ แต้มสะสม และประวัติแต้ม โดยแยก User ID รายอุปกรณ์อัตโนมัติ
- ใช้โลโก้ Full Color และดาวเคราะห์พัซเซิลจากชุดแบรนด์อ้างอิง
- ดาวเคราะห์มุมขวาบน พลิกและเปิดประตูวาร์ป 3 วินาทีไปยังหลังบ้าน
- ระบบสร้าง User ID รายอุปกรณ์อัตโนมัติ ไม่ต้องกรอกรหัสหรือเข้าสู่ระบบ
- อุปกรณ์แรกที่เปิดหลังบ้านหลังติดตั้งจะได้รับสิทธิ์ OWNER อัตโนมัติ อุปกรณ์ลูกค้าหลังจากนั้นจะถูกปฏิเสธ
- COMMAND CENTER, POS, ออเดอร์, ตรวจชำระ, แพ็ก, จัดส่ง, สินค้า/สต็อก, CRM, โปรโมชั่น, การเงิน, รายงาน, ตั้งค่า และแชตแอดมิน
- ขั้นตอนออเดอร์บังคับตามงานจริง: รับงาน → ยืนยันเงิน (กรณีโอน) → เริ่มแพ็ก → ตรวจแพ็ก → จัดส่ง → ปิดออเดอร์
- POS และออนไลน์ใช้ตารางออเดอร์และสต็อกเดียวกัน พร้อมคืนสต็อกอัตโนมัติเมื่อยกเลิก
- เพิ่ม/แก้สินค้า รับล็อตสต็อก และบันทึกต้นทุน FIFO
- ตั้งค่าชื่อร้าน ประกาศ เปิด/ปิดร้าน ค่าส่ง แต้ม ช่องทางติดต่อ ข้อมูลชำระเงิน QR และธีมเทศกาล
- จัดการรหัสตัวแทนจำหน่าย/เด็กส่งยอดและเปอร์เซ็นต์ค่าคอม
- ตารางล็อตสินค้าและต้นทุนจริง พร้อมโครงคำนวณค่าคอมจากกำไรหลังหักต้นทุน

สูตรค่าคอม:

`max(0, ยอดสินค้า - ส่วนลด - ต้นทุนล็อตจริง - ค่าจัดส่ง) × อัตราคอมมิชชัน`

## Deploy ผ่าน GitHub

1. อัปโหลดไฟล์ทั้งหมดในชุดนี้ไว้ที่รากของ Repository `Jigz-store`
2. ตั้ง Build command เป็น `npm install`
3. ตั้ง Deploy command เป็น `npx wrangler deploy`
4. Push เข้า branch `main` แล้ว Cloudflare จะ Deploy อัตโนมัติ

ระบบผูก D1 ด้วยตัวแปร `DB` และสร้างตารางที่จำเป็นอัตโนมัติเมื่อเรียก API ครั้งแรก

รุ่น 4.2.0 ปิด HTML canonical redirect ของ Static Assets เพื่อให้เส้นทาง `/admin` เปิด `admin.html` ได้โดยไม่เกิด `ERR_TOO_MANY_REDIRECTS` และสร้าง VAPID key อัตโนมัติใน D1 (ไม่เก็บ private key ใน GitHub)

## เปิด Web Push

หลัง Deploy ให้เปิด `/admin` บนอุปกรณ์แอดมิน กด `🔔 เปิดแจ้งเตือน` และอนุญาตการแจ้งเตือน จากนั้นกด `⚡ ทดสอบ` ได้ทันที บน iPhone/iPad ต้องเพิ่มเว็บไว้ที่หน้าจอโฮมและเปิดจากไอคอนนั้นก่อน

## การเปิดหลังบ้านครั้งแรก

1. Deploy ระบบให้เรียบร้อย
2. ใช้อุปกรณ์แอดมินหลักเปิดหน้าร้าน
3. กดดาวเคราะห์และรอวาร์ป 3 วินาที
4. ระบบจะสร้าง User ID และกำหนดอุปกรณ์นี้เป็น `OWNER` โดยอัตโนมัติ

หลังมี OWNER แล้ว อุปกรณ์ใหม่จะเริ่มต้นเป็น `CUSTOMER` และไม่สามารถเปิดหลังบ้านได้เอง การล้างคุกกี้ของอุปกรณ์ OWNER จะทำให้รหัสอุปกรณ์เดิมหาย จึงควรใช้เบราว์เซอร์หลักเดิมจนกว่าจะเพิ่มหน้าจัดการอุปกรณ์สำรองในรุ่นถัดไป

ตรวจการเชื่อมฐานข้อมูลได้ที่ `/api/health` ซึ่งควรตอบ `{"ok":true,"database":"connected","version":"4.2.0"}`

> สำคัญ: หลัง Deploy ใหม่ ให้ใช้อุปกรณ์แอดมินหลักเปิด `/admin` เป็นอุปกรณ์แรกและอย่าล้างคุกกี้ของอุปกรณ์นั้น ระบบไม่ใช้หน้าล็อกอินตามข้อกำหนด จึงผูกสิทธิ์กับคุกกี้อุปกรณ์หลัก
