# JIGᶻ AGENT Store — Cloudflare

ระบบหน้าร้านและหลังบ้านสำหรับ JIGᶻ AGENT บน Cloudflare Workers + D1

## ฟังก์ชันในรุ่นนี้

- Web Push Notification สำหรับอุปกรณ์แอดมิน พร้อมปุ่มเปิดและส่งทดสอบ
- หน้าร้าน responsive พร้อมสินค้า ค้นหา ตัวกรอง รายการโปรด และตะกร้าในเครื่อง
- ใช้โลโก้ Full Color และดาวเคราะห์พัซเซิลจากชุดแบรนด์อ้างอิง
- ดาวเคราะห์มุมขวาบน พลิกและเปิดประตูวาร์ป 3 วินาทีไปยังหลังบ้าน
- ระบบสร้าง User ID รายอุปกรณ์อัตโนมัติ ไม่ต้องกรอกรหัสหรือเข้าสู่ระบบ
- อุปกรณ์แรกที่เปิดหลังบ้านหลังติดตั้งจะได้รับสิทธิ์ OWNER อัตโนมัติ อุปกรณ์ลูกค้าหลังจากนั้นจะถูกปฏิเสธ
- COMMAND CENTER พร้อมสรุปออเดอร์ งานรอดำเนินการ และเมนูระบบหลัก
- จัดการรหัสตัวแทนจำหน่าย/เด็กส่งยอดและเปอร์เซ็นต์ค่าคอม
- ตารางล็อตสินค้าและต้นทุนจริง พร้อมโครงคำนวณค่าคอมจากกำไรหลังหักต้นทุน

## Deploy ผ่าน GitHub

1. อัปโหลดไฟล์ทั้งหมดในชุดนี้ไว้ที่รากของ Repository `Jigz-store`
2. ตั้ง Build command เป็น `npm install`
3. ตั้ง Deploy command เป็น `npx wrangler deploy`
4. Push เข้า branch `main` แล้ว Cloudflare จะ Deploy อัตโนมัติ

ระบบผูก D1 ด้วยตัวแปร `DB` และสร้างตารางที่จำเป็นอัตโนมัติเมื่อเรียก API ครั้งแรก

รุ่น 3.1.0 ปิด HTML canonical redirect ของ Static Assets เพื่อให้เส้นทาง `/admin` เปิด `admin.html` ได้โดยไม่เกิด `ERR_TOO_MANY_REDIRECTS` และเพิ่ม Web Push โดยสร้าง VAPID key อัตโนมัติใน D1 (ไม่เก็บ private key ใน GitHub)

## เปิด Web Push

หลัง Deploy ให้เปิด `/admin` บนอุปกรณ์แอดมิน กด `🔔 เปิดแจ้งเตือน` และอนุญาตการแจ้งเตือน จากนั้นกด `⚡ ทดสอบ` ได้ทันที บน iPhone/iPad ต้องเพิ่มเว็บไว้ที่หน้าจอโฮมและเปิดจากไอคอนนั้นก่อน

## การเปิดหลังบ้านครั้งแรก

1. Deploy ระบบให้เรียบร้อย
2. ใช้อุปกรณ์แอดมินหลักเปิดหน้าร้าน
3. กดดาวเคราะห์และรอวาร์ป 3 วินาที
4. ระบบจะสร้าง User ID และกำหนดอุปกรณ์นี้เป็น `OWNER` โดยอัตโนมัติ

หลังมี OWNER แล้ว อุปกรณ์ใหม่จะเริ่มต้นเป็น `CUSTOMER` และไม่สามารถเปิดหลังบ้านได้เอง การล้างคุกกี้ของอุปกรณ์ OWNER จะทำให้รหัสอุปกรณ์เดิมหาย จึงควรใช้เบราว์เซอร์หลักเดิมจนกว่าจะเพิ่มหน้าจัดการอุปกรณ์สำรองในรุ่นถัดไป

ตรวจการเชื่อมฐานข้อมูลได้ที่ `/api/health` ซึ่งควรตอบ `{"ok":true,"database":"connected"}`
