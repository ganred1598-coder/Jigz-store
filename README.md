# JIGᶻ AGENT Store — Cloudflare

ระบบหน้าร้านและหลังบ้านสำหรับ JIGᶻ AGENT บน Cloudflare Workers + D1

## ฟังก์ชันรุ่น 5.4.0

- OWNER ลบออเดอร์ที่สำเร็จหรือยกเลิกแล้วออกจากหน้าทำงานได้ พร้อมระบุเหตุผลและยืนยันสองครั้ง
- ใช้การลบแบบปลอดภัย: ซ่อนออเดอร์จากหน้าทำงาน แต่เก็บรายการสินค้า การเงิน ค่าคอม และ Audit เดิมไว้
- เพิ่มปุ่มลัด `สร้างออเดอร์`, `แต่งตั้งผู้ดูแล`, `เพิ่มตัวแทน` และ `สร้างโปรโมชั่น` ในหัวข้อหน้าที่เกี่ยวข้อง

- ปิดเรทราคาที่จำนวนคงเหลือไม่ถึง และคำนวณจำนวนแพ็กสูงสุดตามสต็อกจริง
- ตรวจสต็อกรวมของสินค้าชนิดเดียวกันทุกเรทในตะกร้า ก่อนเข้าหน้าชำระเงินและก่อนสร้างออเดอร์
- ป้องกันการเพิ่มจำนวนด้วยปุ่ม `+` เมื่อสต็อกไม่พอ พร้อมตรวจซ้ำฝั่งเซิร์ฟเวอร์และ FIFO

- เพิ่มตัวสร้างเรทราคามาตรฐาน `1G / 10G / 30G / 50G / 100G / 500G / 1000G` ในปุ่มเดียว
- เปลี่ยนการกรอกราคาตามขนาดจาก JSON เป็นแถวจำนวนและราคารวม พร้อมตรวจช่องซ้ำหรือข้อมูลไม่ครบ
- หน้าร้านแสดงป้ายขนาดที่มีจำหน่ายบนการ์ดสินค้า และแสดงเรทแบบ `1G`, `10G` ในเมนูเลือกสินค้า

- ใส่ชื่อกำกับและคำอธิบายทุกช่องในฟอร์มเพิ่ม/แก้ไขสินค้า พร้อมตัวอย่างการกรอกสต็อก ต้นทุน และราคาตามขนาด

- แยก OWNER หลัก 1 คนและ OWNER รองสูงสุด 4 คน โดยมีตัวนับจำนวนและป้ายสิทธิ์ชัดเจน
- OWNER ทุกคนส่งคำขอลบ OWNER รองได้ แต่จะลบจริงเมื่อ OWNER หลักกดยืนยันเท่านั้น และ OWNER หลักถูกป้องกันไม่ให้ลบ
- เพิ่มประวัติคำขอ อนุมัติ/ปฏิเสธ และ Audit สำหรับการแต่งตั้งหรือลบ OWNER ทุกขั้นตอน
- เพิ่มภาพเคลื่อนไหวอวกาศแบบเบา ดาวกะพริบ แสงลอย และดาวเคราะห์ลอยช้าโดยไม่บังเนื้อหา
- ปรับ Responsive UI/UX สำหรับมือถือจอเล็ก จอพับ แท็บเล็ต แนวนอน และ Safe Area พร้อมรองรับ Reduce Motion

- ปิดยอดรายวันและรายเดือนตามเวลาไทย พร้อม Snapshot รายรับ ต้นทุนจริง FIFO กำไร ค่าคอม เงินสด/COD และเครดิตฝากถอน
- บันทึกเงินสดนับจริงและแสดงส่วนต่าง เปิดดู พิมพ์ หรือบันทึกรายงานเป็น PDF ได้
- OWNER ลบลูกค้าหรือผู้ดูแลระบบได้แบบปลอดภัย โดยเก็บออเดอร์และ Audit เดิมไว้ ยกเลิก Session และป้องกันการลบ OWNER
- บล็อกการลบผู้ใช้ที่ยังมีเครดิตหรือคำขอฝากถอนค้างตรวจ

- กระเป๋าเครดิตแยกตาม User ID อัตโนมัติ ลูกค้าดูยอด เติมเครดิต แนบสลิป ขอถอน และดูประวัติธุรกรรมได้
- ตรวจสลิปธนาคารด้วย EasySlip API v2 โดยตรวจยอดเงิน บัญชีผู้รับ และสลิปซ้ำก่อนเพิ่มเครดิต
- หาก EasySlip ยังไม่ได้ตั้งค่า โควตาหมด หรือผู้ให้บริการไม่พร้อม ระบบจะพักคำขอไว้ให้แอดมินตรวจ ไม่เพิ่มเครดิตอัตโนมัติ
- หน้า `เครดิต ฝาก / ถอน` ในหลังบ้านสำหรับเปิดดูสลิป อนุมัติ/ปฏิเสธคำขอ และยืนยันการโอนถอนเงิน
- เชื่อม User ID ของลูกค้ากับตัวแทนจำหน่ายหรือเด็กส่งยอด เพื่อรับค่าคอมเข้ากระเป๋าโดยไม่ต้องล็อกอิน
- จ่ายค่าคอมเฉพาะออเดอร์สำเร็จ โดยคำนวณหลังหักต้นทุน FIFO จริง แล้วเข้ากระเป๋าทุกวันอาทิตย์เวลา 17:00 น. ประเทศไทย
- ปุ่มจ่ายค่าคอมทันทีสำหรับตรวจระบบหรือดำเนินการก่อนรอบอัตโนมัติ พร้อมล็อกรายการที่จ่ายแล้วไม่ให้แก้ยอดซ้ำ

- ออกแบบหน้ากรอกข้อมูลจัดส่งและชำระเงินใหม่ แบ่งขั้นตอนชัดเจนและรองรับมือถือ
- ขยาย QR Code ให้อ่านง่าย พร้อมปุ่มดาวน์โหลดรูปลงอุปกรณ์
- เพิ่มปุ่มคัดลอกเลขบัญชีและข้อความยืนยันเมื่อคัดลอกสำเร็จ
- สรุปยอดสินค้า ค่าจัดส่ง และยอดชำระทั้งหมดในแถบยืนยันที่มองเห็นง่าย

- เพิ่มเอฟเฟกต์ดาวหลากสีแบบสุ่ม พุ่งจากปุ่มเพิ่มสินค้าไปยังตะกร้าทุกครั้งที่ลูกค้าเพิ่มสินค้า

- แก้ปุ่ม `เลือกสินค้า` ให้เลื่อนไปรายการสินค้าจริง พร้อมเอฟเฟกต์เน้นพื้นที่แคตตาล็อก

## Deploy ผ่าน GitHub

1. อัปโหลดไฟล์ทั้งหมดในชุดนี้ไว้ที่รากของ Repository `Jigz-store`
2. ตั้ง Build command เป็น `npm install`
3. ตั้ง Deploy command เป็น `npx wrangler deploy`
4. Push เข้า branch `main` แล้ว Cloudflare จะ Deploy อัตโนมัติ

ระบบผูก D1 ด้วยตัวแปร `DB` และสร้างตารางที่จำเป็นอัตโนมัติเมื่อเรียก API ครั้งแรก

รุ่น 5.4.0 ปิด HTML canonical redirect ของ Static Assets เพื่อให้เส้นทาง `/admin` เปิด `admin.html` ได้โดยไม่เกิด `ERR_TOO_MANY_REDIRECTS` สร้าง VAPID key อัตโนมัติใน D1 เพิ่มระบบกระเป๋า/ตรวจสลิป ระบบปิดยอด การควบคุม OWNER แบบยืนยันสองขั้น ฟอร์มสินค้าที่มีคำกำกับชัดเจน ตัวสร้างเรทราคาหลายขนาด การล็อกออเดอร์ตามสต็อกจริง และการลบออเดอร์แบบเก็บหลักฐานโดยไม่เก็บคีย์ลับใน GitHub

## เปิดตรวจสลิป EasySlip

1. ใน EasySlip Developer ให้สร้าง API key และเพิ่มบัญชีธนาคารผู้รับเงินของร้านให้กับแอป/สาขาที่ใช้งาน
2. ไปที่ Cloudflare Worker → `Settings` → `Variables and Secrets`
3. เพิ่มตัวแปรแบบ **Secret** ชื่อ `EASYSLIP_API_KEY` แล้ววาง API key เป็นค่า
4. Deploy ใหม่หนึ่งครั้ง จากนั้นลองเติมเครดิตด้วยสลิปจริงที่ยอดตรงกัน

ห้ามใส่ API key ใน GitHub, `wrangler.jsonc`, JavaScript ฝั่งเบราว์เซอร์ หรือส่งคีย์ในแชต ระบบจะส่งรูปสลิปจาก Worker ไปยัง `POST https://api.easyslip.com/v2/verify/bank` เท่านั้น

การถอนเครดิตเป็นคำขอแบบตรวจสอบโดยแอดมิน: ระบบกันยอดทันที แต่แอดมินต้องโอนเงินผ่านธนาคารจริงก่อนกดอนุมัติ ระบบไม่ได้สั่งโอนเงินจากบัญชีธนาคารให้อัตโนมัติ

## รอบจ่ายค่าคอม

Cloudflare Cron Trigger ตั้งเป็น `0 10 * * SUN` หรือทุกวันอาทิตย์ 10:00 UTC / 17:00 น. ประเทศไทย ระบบจะจ่ายเฉพาะค่าคอมของออเดอร์สถานะ `COMPLETED` และตัวแทนที่เชื่อม User ID แล้ว สามารถทดสอบได้จากหลังบ้าน → `เครดิต ฝาก / ถอน` → `จ่ายค่าคอมตอนนี้`

## เปิด Web Push

หลัง Deploy ให้เปิด `/admin` บนอุปกรณ์แอดมิน กด `🔔 เปิดแจ้งเตือน` และอนุญาตการแจ้งเตือน จากนั้นกด `⚡ ทดสอบ` ได้ทันที บน iPhone/iPad ต้องเพิ่มเว็บไว้ที่หน้าจอโฮมและเปิดจากไอคอนนั้นก่อน

## การเปิดหลังบ้านครั้งแรก

1. Deploy ระบบให้เรียบร้อย
2. ใช้อุปกรณ์แอดมินหลักเปิดหน้าร้าน
3. กดดาวเคราะห์และรอวาร์ป 3 วินาที
4. ระบบจะสร้าง User ID และกำหนดอุปกรณ์นี้เป็น `OWNER` โดยอัตโนมัติ

หลังมี OWNER แล้ว อุปกรณ์ใหม่จะเริ่มต้นเป็น `CUSTOMER` และไม่สามารถเปิดหลังบ้านได้เอง การล้างคุกกี้ของอุปกรณ์ OWNER จะทำให้รหัสอุปกรณ์เดิมหาย จึงควรใช้เบราว์เซอร์หลักเดิมจนกว่าจะเพิ่มหน้าจัดการอุปกรณ์สำรองในรุ่นถัดไป

ตรวจการเชื่อมฐานข้อมูลได้ที่ `/api/health` ซึ่งควรตอบ `{"ok":true,"database":"connected","version":"5.4.0"}`

> สำคัญ: หลัง Deploy ใหม่ ให้ใช้อุปกรณ์แอดมินหลักเปิด `/admin` เป็นอุปกรณ์แรกและอย่าล้างคุกกี้ของอุปกรณ์นั้น ระบบไม่ใช้หน้าล็อกอินตามข้อกำหนด จึงผูกสิทธิ์กับคุกกี้อุปกรณ์หลัก
